
# Selam Dilnesa - Personal Portfolio / Blog

A personal, blog-style portfolio built with semantic HTML5 by Selam Dilnesa. This site serves as a space to share my journey, background, interests, and connections as a student and aspiring developer.

---

## Features

- **Semantic HTML5 Structure:** Built using proper HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<address>`, and `<footer>`).
- **Interactive Information:** Built-in collapsible details elements (`<details>` and `<summary>`) for quick facts like favorite show, birthday, and music artists.
- **Embedded Media:** Integrated embedded `<iframe>` elements to display interactive photo/video galleries (`i-frame.html` and `iframe2.html`).
- **Contact Form:** Interactive feedback form with input fields, drop-down menu selections, and contact links.
